# Da Mộc

Trang giới thiệu (landing page) **tĩnh** — da Mộc — xưởng đồ da thủ công: ví, túi, thắt lưng, dây đồng hồ và đồ da đặt riêng, khâu tay từng mũi chỉ. Trang được dựng bằng HTML, CSS và JavaScript thuần, không cần bước biên dịch.

> Mọi tên, số điện thoại, địa chỉ và số liệu trên trang đều là **dữ liệu mẫu**. Giá hiển thị là **giá mẫu**. Biểu mẫu (nếu có) chỉ là giao diện minh họa: không gửi dữ liệu đi đâu và không có backend.

**Demo trực tuyến:** https://m-software-da-moc.genalpha.dev
**Giấy phép:** [MIT](LICENSE) © M-Software

## English

A **static** landing page for Da Mộc, built with plain HTML, CSS and JavaScript. All names, contact details and figures shown are sample data, displayed prices are sample prices, and any form is interface-only — nothing is submitted and there is no backend. Open `index.html` in a browser. Licensed under MIT.
